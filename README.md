# 📖 Projektbeschreibung

Dieses Repository enthält das Uni-Projekt des Moduls **Mobile Technologien**.

Im Rahmen des Projekts entwickeln wir gemeinsam eine **native Android-App** mit **Kotlin** unter Verwendung von **Android Studio**.

Der Fokus liegt auf:
- 📱 Entwicklung moderner Android-Anwendungen  
- 🏗️ Softwarearchitektur & saubere Projektstruktur  
- 🤝 Teamarbeit & Versionsverwaltung mit Git/GitHub  
- 🚀 Praktischer Einsatz mobiler Technologien  

> Features und konkrete Anwendungsfälle werden im Verlauf des Projekts ergänzt.
